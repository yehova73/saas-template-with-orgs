## Gaps & Missing Pieces

### 🔴 Critical — Template Can Break Without These

#### 1. No `middleware.ts`

Route protection is done entirely via server-side redirects inside layouts/pages. There is no centralized Next.js middleware guarding `/app/*`. Any route that lacks a layout check is silently public.
**Fix:** Add `middleware.ts` that validates the session on all `/app/**` paths before the page renders.

#### 2. `UserQuickStartActions` schema has no boolean columns

`actions/quick-start/mark-quick-start-action-complete.ts` tries to upsert columns like `createdFirstTemplate`, `addedFirstClient`, etc., but those fields **do not exist** in the Prisma schema. Every call silently fails or throws.
**Fix:** Add the boolean columns to the `UserQuickStartActions` model in `prisma/schema.prisma`.

#### 3. `activeProjectId` lives in JWT only — not persisted in DB

When a user signs in from a second device or their JWT expires, `activeProjectId` is gone. This is also not on the `User` model in Prisma.
**Fix:** Add `activeProjectId String?` (nullable FK to `Project`) on the `User` model and sync it on JWT callbacks.

#### 4. `export-data.ts` is a stub

The GDPR/data-export action returns a dummy object — no actual data is fetched or exported.
**Fix:** Implement a real export (query user + memberships + org data, return as JSON or ZIP).

#### 5. Sidebar "Requests" link has no route

`/app/${projectId}/requests` is in the sidebar nav but no corresponding page exists. Clicking it will 404.
**Fix:** Create the route or remove the nav item until it's implemented.

### 🟠 Important — Common SaaS Expectations

#### 6. No Audit / Activity Log

No model tracks who did what and when (renamed org, added member, changed billing, etc.). This is expected by teams and often required for compliance.
**Schema addition needed:**

```prisma
model AuditLog {
  id             String   @id @default(cuid())
  organizationId String
  userId         String?
  action         String
  resourceType   String?
  resourceId     String?
  metadata       Json?
  createdAt      DateTime @default(now())

  organization Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)
  user         User?        @relation(fields: [userId], references: [id], onDelete: SetNull)
}
```

#### 8. No `error.tsx` / `not-found.tsx` / `loading.tsx` pages

Only `/change-email/loading.tsx` exists. Without these:

- Unhandled errors show Next.js's default ugly error page in production.
- Route transitions have no loading skeleton fallback in most areas.

#### 9. Admin panel is a stub

`actions/admin/contact.ts` exists but there's no admin UI, no admin role on the `User` model, and no route under `/admin/**`. The contact requests stored in the DB are inaccessible.

#### 10. No rate limiting on server actions / API routes

`express-rate-limit` appears in `package-lock.json` as a transitive dep — it's not applied to anything. Password resets, login attempts, and invite emails have no throttle.

#### 11. Trial box is commented out on the dashboard

```tsx
// {sub.states.isTrialActive && ( <TrialBox ... /> )}
```

The trial model is wired in the DB (`trialStartedAt`, `trialEndsAt`) but the UI component is commented out. Users can't see they're on a trial.

#### 12. Stripe cancellation is commented out in `deleteAccountAction`

When a user deletes their account, their active Stripe subscription is not cancelled. The cleanup code exists but is commented out, meaning deleted users keep being charged.

#### 13. No pagination helpers

Projects, memberships, and invites are fetched with no limit. This will degrade silently as data grows. No cursor-based or offset pagination pattern is established.

#### 14. No global search

No search over projects or members within an organization.

### 🟡 Nice to Have — Standard SaaS Polish

#### 15. No `.env.example`

No documented list of required env vars. Anyone trying to run this needs to reverse-engineer them from the source.
Required vars include: `DATABASE_URL`, `NEXTAUTH_SECRET`, `NEXTAUTH_URL`, `NEXTAUTH_GOOGLE_CLIENT_ID`, `NEXTAUTH_GOOGLE_CLIENT_SECRET`, `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, Brevo/SMTP keys, etc.

#### 16. No `sitemap.xml` / `robots.txt`

The public landing and policy pages have no SEO infrastructure.

#### 17. No API key model for programmatic access

No way for an org to generate tokens for server-to-server integrations. Common in SaaS.

```prisma
model ApiKey {
  id             String    @id @default(cuid())
  organizationId String
  name           String
  keyHash        String    @unique
  lastUsedAt     DateTime?
  expiresAt      DateTime?
  createdAt      DateTime  @default(now())
  revokedAt      DateTime?
  organization   Organization @relation(fields: [organizationId], references: [id], onDelete: Cascade)
}
```

#### 18. No outgoing webhook support

No way for customers to subscribe to events (project created, member added, etc.).

#### 19. No notification inbox

`UserNotificationSettings` tracks preferences but there's no `Notification` model or inbox UI. Prefs without an inbox do nothing.

### 🔵 Template Hygiene — Before Reusing Across Projects

#### 20. `package.json` name is `"docushare"` — a previous project's name

#### 21. `SENDER_DOMAIN` is hardcoded as `"fluxgate.app"` in `lib/emails/email-service.ts`

#### 22. `next.config.ts` has a hardcoded S3 hostname from a previous project

```ts
hostname: "percevo-review-images-bucket.s3.us-east-1.amazonaws.com";
```

This should be removed or replaced with an env-driven config.

#### 23. `console.log` in production code

- `lib/auth.ts`: `console.log("credentials", ...)` — logs plaintext passwords to stdout
- `app/(dashboard)/layout.tsx`: `console.log(user)` — logs session data

#### 24. App-specific dependencies that don't belong in a generic template

Remove these before reusing — they're from a previous project:

- `@googleworkspace/drive-picker-react`
- `react-gdrive-picker`
- `jszip`
- `xlsx`
- `html-to-text`
- `@dnd-kit/*` and `@hello-pangea/dnd` (two competing DnD libraries — pick one or remove both)
- `@faker-js/faker` — in **production** deps, should be devDependency or removed entirely

#### 25. Unrelated types in devDependencies

- `@types/chrome` — browser extension types, not needed
- `@types/papaparse` — CSV parsing, not needed

#### 26. `re2` listed in `serverExternalPackages` in `next.config.ts` but not in `package.json` dependencies
